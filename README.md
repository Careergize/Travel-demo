# OneTravels

Run `npm install` and `npm run dev` from this folder. Use `npm run build` to create the production site in `dist`.

To enable WhatsApp enquiries, create `.env.local` with `VITE_WHATSAPP_NUMBER` set to the OneTravels business number, including the country code. Restart the development server or rebuild for production. The form prepares a message for the visitor to send in WhatsApp. Without a configured number, visitors can copy the prepared message.

Review the sample trip itineraries and transport options against your actual services before publishing.
